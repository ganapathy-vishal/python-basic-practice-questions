# python-basic-practice-questions
basic questions on python programs using functions,args,kwargs,etc
1. Create a function that accepts a number and returns its square.

2. Create a function that accepts a list and returns only the even numbers.

3. Create a function that accepts a string and returns the reversed string.

4. Create a function that returns True if a number is positive.

5. Create a function that accepts a list of numbers and returns their average.

6. Write a lambda function to convert Celsius to Fahrenheit.

7. Create a function that accepts any number of values using *args and returns the largest value.

8. Create a function that accepts details using **kwargs and displays them neatly.

9. Create a function that counts the number of vowels in a string.

10. Create a function that calculates the final price after applying a discount.
